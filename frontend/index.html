TECHNICAL SPECIFICATIONS

Verified Engineering Architecture

DEFECTX AI is built on verifiable open-set anomaly detection principles. Every component reflects our actual PyTorch implementation, normal-only validation, and hardware-conscious design.

Deep Feature Extraction

Pretrained ResNet-18 with frozen weights extracts mid-level representations from layer2 (128-ch) and layer3 (256-ch). Local average pooling aligns them into 384-dimensional patch tokens at 28x28 spatial resolution.

Pretrained ResNet-18 (384-dim Tokens)

Memory Bank Anomaly Detection

PatchCore-inspired one-class baseline trained strictly on normal images. Features are subsampled using greedy minimax k-center coreset selection (10% ratio) with chunked L2 Euclidean nearest-neighbor search.

Greedy Minimax Coreset Subsampling

AI Heatmap & Defect Localization

Upsamples patch distance scores back to 224x224 input resolution via bilinear interpolation, smooths spatial noise with Gaussian filtering (σ = 4.0), and generates colorized JET anomaly overlays for human inspection.

Bilinear Upsampling & Gaussian Smoothing

Validation-Based Threshold Calibration

Decision thresholds are fitted exclusively on a held-out normal validation split (val/good) using the 99.0th percentile with a 1.05 safety margin. Test defect images are strictly excluded from threshold fitting.

Normal-Only Percentile Fitting

Heuristic Severity Assessment

Triage levels are estimated by combining anomalous area ratio (percentage of pixels exceeding threshold) and peak anomaly intensity into NONE, LOW, MEDIUM, HIGH, and CRITICAL categories as an operational heuristic prototype.

Heuristic Prototype (Not Physical Measurement)

Hardware-Accelerated AI Inference

Executes PyTorch in inference mode with NVIDIA CUDA acceleration and CPU fallback. Integrates with PHP enterprise backends via a clean CLI interface (JSON on stdout, logs on stderr, automated --health check).

PyTorch CUDA Runtime & PHP CLI Interface

PyTorch / ResNet-18
