PatchCore Memory Bank Architecture

DEFECTX AI implements an open-set industrial defect detection baseline inspired by PatchCore. In real-world factory production lines, defects are rare, unpredictable, and infinite in variety. Supervised multi-class classifiers fail when encountering novel structural flaws.

1. Mid-Level Feature Extraction
Instead of using final classification layers (which discard spatial localized texture), DEFECTX AI taps intermediate feature maps from layer2 and layer3 of a ResNet-18 backbone pretrained on ImageNet. Features are spatially harmonized via adaptive average pooling.
2. Greedy Coreset Selection
To prevent GPU memory saturation on our 6GB NVIDIA RTX 4050, the normal feature memory bank is subsampled using a greedy minimax distance approximation. This preserves the topological boundary of normal representations with a 10x reduction in memory footprint.
3. Nearest-Neighbor Anomaly Scoring
During inference, every patch in the query image is compared against its nearest neighbor in the coreset memory bank using Euclidean distance. The maximum patch distance represents the image-level anomaly score:
s* = max_{m ∈ M_test} min_{n ∈ M_bank} ||m - n||_2
Zero-Leakage Calibration Methodology
100% Defensible

In competitive evaluations, a critical pitfall is tuning detection thresholds on test defect samples, which creates artificial data leakage.

  • Train Split: 209 clean normal images used exclusively to construct the memory bank.
  • Validation Split: 20 held-out normal images used exclusively to fit the decision threshold (at 99.5th percentile = 3.5042).
  • Test Split: 20 normal images and 63 defective images strictly held-out. They were never seen during memory bank construction or threshold calibration.
Anomaly Score vs Probability
Why Anomaly Score ≠ Probability:

The Euclidean distance between query features and memory-bank representations is an unbounded metric [0, ∞). In DEFECTX AI, we explicitly do not label raw scores as Bayesian probabilities.

Confidence percentages reported in the UI represent relative margin distance above the validation threshold calibrated via sigmoidal scaling, clearly distinguishing empirical distance from true posterior probability.
